FPGA Top-Down Racing Game

A top-down racing game written in C, running on a Zybo Z7-7020. Video output goes through VDMA to a 640×480 framebuffer in BGR byte order, with double-buffering to keep things smooth.

16th July 2026

    So far I've got a tile-based track system running on a 40×30 grid with 16px tiles, four-directional car sprites, a pixel-art lap timer hand-drawn digit by digit, collision detection with wall reversion and a frame penalty, and a lap times table. For a while, crossing the finish line logged three lap entries instead of one. Turned out the trigger was firing on every frame the car overlapped the line, not just once per crossing. Fixed it with rising-edge detection and a wasOnFinish flag, so it only counts the moment the car transitions onto the line rather than every frame it's sitting on it. Still on the list: the finish line technically spans three tile rows, which might need a coordinate-based check down the line instead of a tile check. But for now it does function the way I need it. So I would have to check later if this is still needed or not. Running at roughly 18fps right now, measured empirically.
