Mom: We have Jarvis at Home

Hard to say whether I would call this a project, but its something a little fun. Basically trying to make a Jarvis like program. Obviously it's not as smart as Jarvis, but I can only try.

19th August 2026

    So as of right now, using openwakeword we're listening out for "Hey Jarvis". Before then taking in a prompt or question, this is handled by faster-whisper, which takes in 5 seconds of audio and transcribes it. We are then taking this text and feeding it to the local model which for me is llama 3.2:3b for the time being. The plan from here is to implement TTS (Text To Speech) which will allow us get a spoken response back from llama or whatever model you may end up using, I'll be using Piper for this.
