F1 Race Dashboard

A live race dashboard running directly on a Raspberry Pi 4, pulling data from the OpenF1 API. It went through a full rewrite — the first attempt used Flask-SocketIO in Docker, but ran into frontend rendering issues, so I moved to a cleaner direct-on-Pi Python venv setup instead. This will likely change later, but it will stay the same for now, especially until I can set up the front end to look pretty along with getting live data to show up reliably.

21st July 2026

    Six OpenF1 endpoints are wired up and returning live data now. I had to build a rather simple background caching thread to stop the HTTP 429 rate-limit errors I kept hitting. limit=1 isn't supported by the OpenF1 API, so I swapped to using session_key=latest to get the most up-to-date info instead. /intervals only populates data during live sessions, which took a minute to figure out, and at one point the frontend was rendering literal "undefined" strings before I added proper fallback handling.

18th July 2026

    The frontend is tabbed so that the different info types are seperated now. I have also gotten the page to auto update through auto polling around every 15 seconds to prevent any rate-limit errors from taking place again.
